# IT Support Ticket Triage Automation

A beginner Python project that automates sorting IT support tickets. It reads tickets from a CSV file, assigns a category and a priority using simple keyword rules, writes a sorted CSV, charts the results and includes basic tests. The tickets are made-up sample data.

Tools: Python, csv, matplotlib, Google Colab
What it automates: manual reading and sorting of a support inbox
Possible next steps: read real email tickets, add a database, build a simple web form
